# Multi-Task Multi-Behavior MAP-Elites (MTMB-ME)

[MTMB-ME](https://arxiv.org/abs/2305.01264) combines MAP-Elites for the search
for diversity and Multi-task MAP-Elites for leveraging similarity between
tasks: given a set of tasks, it builds one archive of diverse and
high-performing solutions per task, all the archives sharing the same
tessellation of the behavior space.
